Análise de Evasão Escolar no Brasil

Projeto de análise exploratória e visualização de dados voltado à identificação de padrões de evasão escolar em um conjunto de dados simulado sobre o Brasil. A análise compara redes de ensino, regiões, evolução temporal e indicadores associados ao risco de abandono.

A rede pública apresenta uma taxa média de evasão mais de duas vezes superior à rede privada, indicando um ponto prioritário para investigação e intervenção.

Objetivo

O objetivo do projeto é aplicar Python, Pandas, Matplotlib, Seaborn e Streamlit em um fluxo completo de análise de dados, desde a leitura e limpeza da base até a construção de KPIs, gráficos e um dashboard interativo.

Tratamento

Conversão de datas, verificação de dados ausentes, checagem de duplicidades e preparação da base.

Indicadores

Cálculo da taxa média de evasão, evasão por rede de ensino, região, ano e nível de risco.

Dashboard

Visualizações com filtros interativos, tabelas, KPIs dinâmicos e conclusão executiva.

Principais Insights

Rede de ensino

A evasão média na rede pública é de aproximadamente 10,40%, contra 4,13% na rede privada.

Distribuição regional

As regiões apresentam diferenças moderadas, com taxas médias próximas ao intervalo de 7%.

Evolução temporal

Entre 2015 e 2024, a taxa de evasão oscila, com 2016 entre os anos de maior média e 2019 entre os menores.

Tecnologias

O projeto integra análise de dados, visualização e publicação online, atendendo aos requisitos da avaliação G2.

  • Python para desenvolvimento da análise.
  • Pandas para leitura, tratamento e criação de indicadores.
  • Matplotlib e Seaborn para visualizações exploratórias.
  • Streamlit para construção do dashboard interativo.
  • GitHub para versionamento e GitHub Pages para publicação desta página.

Conclusão Executiva

A análise mostra que a evasão escolar não se distribui de forma uniforme. O principal destaque está na diferença entre redes de ensino, com maior vulnerabilidade na rede pública. Indicadores como desempenho, renda familiar, acesso à internet e nível de risco ajudam a direcionar ações preventivas e políticas de permanência escolar.

Próximas ações recomendadas

  • Acompanhar alunos e regiões classificados com maior risco.
  • Investigar fatores socioeconômicos associados à permanência escolar.
  • Usar o dashboard como apoio para priorização de ações de retenção.
